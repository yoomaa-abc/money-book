# Money Book · 살림결

업로드한 money book 폴더의 Android 가계부 프로젝트와 배포 자료입니다.

- `salimgyeol/`: 최신 1.3.4 소스와 빌드·검증 안내
- `dalsseum-desktop-test/`: Node.js로 실행하는 데스크톱 확인용 앱 (`node server.cjs`)
- 루트 APK, 스크린샷, 안내 문서: 버전별 배포 자료
- `*-source.zip`, `dalsseum-source.zip`: 서명 개인키와 비밀번호를 제거한 소스 압축 파일

서명 개인키는 업로드하지 않았습니다. 원본 키는 별도로 보관하고 빌드할 때 `ANDROID_KEYSTORE_PASSWORD`를 설정하세요.

최신 설치 파일: [salimgyeol-1.3.4.apk](salimgyeol-1.3.4.apk). 기존 앱을 삭제하지 말고 업데이트로 설치하세요.
